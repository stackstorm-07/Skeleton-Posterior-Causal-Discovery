# M4 – SPOT vs ABIC on PetShop (CSE 516, team g6)

**Team g6** (`g6_th_apl_cybersecurity_team`): Anant Narayan, Ankit Kumar, Milan Shah.
Course: CSE 516, Probabilistic Graphical Models. Final submission (M4), deadline Thu 12 Nov 2026, 11:59 PM.

## What this project is

We compare two score-based learners of ancestral acyclic directed mixed graphs (ADMGs) from observational data:

* **ABIC** (Bhattacharya et al., 2021): a differentiable BIC search over all candidate directed and bidirected edges. It is the baseline.
* **SPOT** (Ma et al., KDD 2024): the same optimizer, restricted by a learned **skeleton posterior** (a gradient-boosting cascade that predicts which pairs are adjacent). The posterior gives a stochastic mask and, in our calibrated variant **SPOT-cal**, a hard floor that prunes unlikely pairs.

We evaluate on the **PetShop** microservice benchmark (4 scenarios) and on simulated ADMGs. The goal is not to make the PGM win but to find when it helps. We stated five hypotheses before the experiments and report them whichever way they came out.
The full model, learning, inference and baseline code is in `Code/src/`. Everything in the report is generated by scripts from result files; no table is typed by hand.

## Main findings

All numbers come from `Results/aggregate/tables/` (the aggregator output of the submitted run). A difference is called "supported" only if the paired t-test p < 0.05, the Wilcoxon p < 0.05 and the 95% CI excludes 0.

| Question | Result |
|---|---|
| Accuracy on simulated graphs (E1, d = 25, 10 graphs per n) | SPOT-cal skeleton F1 is higher than ABIC by +0.067, 95% CI [+0.044, +0.090] (pooled, 40 units). Supported at n = 200, 1000, 2000; not at n = 500. No evidence that the gain shrinks with n. |
| Accuracy on PetShop (E3, 4 scenarios x 5 seeds) | Small gain: skeleton F1 +0.029 [+0.014, +0.045], PAG-SHD -3.9 [-5.4, -2.4] (pooled, 20 units). Not detectable in any single scenario with 5 seeds. Under block-bootstrap resampling (E5) the mean gain is +0.022 and its interval spans 0. |
| Speed on PetShop | Mean time 376 s (ABIC) to 47 s (SPOT-cal). At an equal 60 s budget on a quiet machine, SPOT-cal converged in 11 of 12 runs, ABIC in 1 of 12 (E6). |
| Where the speed comes from (E4) | Hard floor alone: time ratio 0.23 of ABIC; mask alone: 0.40; both (SPOT-cal): 0.15. No ablation variant differs from ABIC on skeleton F1. |
| Posterior quality (E7) | Calibrated on simulated graphs (ECE 0.0015), over-confident on PetShop (ECE 0.052-0.069, over-confidence about +0.05). An oracle posterior would lift PetShop skeleton F1 from 0.54 to 0.81. |
| Use of the model (E8, E12) | A fitted ADMG predicts held-out data better than no structure (+0.75 nats) and better than a DAG; it is shown no worse than a saturated Gaussian only for the true graph. Learned graphs did not improve root-cause ranking; the true graph did (+0.068 MRR). |
| Classical baselines (E9) | FCI/RFCI are more accurate than ABIC and SPOT-cal on our simulated graphs (F1 0.87-0.89 vs 0.76) and about 40x faster; on PetShop all methods are near 0.5 F1. |
| Scalability (partial) | Plain ABIC diverges at d = 100 with its default start. SPOT-cal keeps a skeleton-F1 lead over a scaled-start ABIC on all seeds at d = 25, 50, 100. d = 200 did not complete. |

Hypothesis scorecard: H1 partly supported, H2 supported, H3 partly supported, H4 supported, H5 partly supported (`Results/aggregate/scorecard.md`).

## Limitations (read before quoting results)

* One experiment is incomplete: E2 finished 79 of 80 jobs. E11 (error analysis) and the d = 200 scalability point were not produced, and the wide-posterior experiments are not part of the submitted results. See `Code/README.md`, section 8.
* PetShop has one fixed series per scenario, so PetShop seeds measure optimizer variance only. With 5 seeds no per-scenario difference can pass the decision rule.
* The main pass (E1-E5, E7, E9, E10, E12, E13) ran with 11 jobs at once on one machine. Times in those files are for comparing methods under the same load, not idle-machine speeds. E6 and E8 were run on a quiet machine.
* The main-pass result files carry no code-version stamps (the stamps were added afterwards). E6, E8 and the scalability files carry them.

## How to reproduce

Short version (full instructions, environment, seeds and troubleshooting are in `Code/README.md`):

```bash
cd Code/src
python -m venv venv && source venv/bin/activate && pip install -r requirements.txt
export CAUSAL_CMD_JAR=/abs/path/causal-cmd-1.3.0-jar-with-dependencies.jar      # Java 17+ required
export PETSHOP_ROOT=/abs/path/to/petshop-root-cause-analysis/dataset
bash run_all.sh main  <physical cores - 1>    # main pass + tables and figures
bash run_all.sh quiet <cores / 2>             # machine otherwise idle: E6, E8, scalability
```

The main pass took about 6 hours on a 22-thread laptop CPU (11 workers); the quiet pass for E6 and E8 took under 6 minutes. A full scalability sweep takes several hours more.
